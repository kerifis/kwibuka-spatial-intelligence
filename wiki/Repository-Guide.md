## Important Files

| Path | Purpose |
| --- | --- |
| `index.html` | Static DOM shell, header controls, map container, info card, testimonies modal, stats panel, timeline, AI modal. |
| `src/main.js` | Application bootstrap, update loop, global event bindings for inline HTML handlers. |
| `src/styles.css` | Full visual system: layout, map layers, display modes, timeline, cards, mobile behavior. |
| `data/schema.md` | Existing data schema documentation. |
| `DEPLOYMENTS.md` | Historical deployment log and feature changes. |
| `README.md` | Public-facing project overview and quick start. |

## Source Directory

`src/` is a set of plain ES modules. There is no component framework. DOM nodes are mostly selected by id or class from `index.html`, and D3 writes SVG elements into layer groups created by `map.js`.

```text
src/
|-- main.js       # app state, boot, update loop, global bindings
|-- map.js        # D3 projection, SVG layers, topology, zoom
|-- timeline.js   # scrubber, playback, phase bars
|-- sigmoid.js    # casualty model and date helpers
|-- heatmap.js    # event and province heat circles
|-- markers.js    # historical event markers
|-- memorials.js  # memorial diamond layer and synthetic local sites
|-- rpf.js        # RPF routes, unit markers, route cards
|-- infocard.js   # floating card, tabs, video pool, testimony modal
|-- stats.js      # side panel counters, province bars, event list
|-- filters.js    # STD/NVG/CRT/FLIR display modes
|-- hist.js       # 1994 administrative map overlay
`-- gemini.js     # optional Gemini synthesis call
```

## Public Assets

`public/` contains static files served from the site root. For example, `public/ibingira.jpg` is referenced as `/ibingira.jpg`.

Asset types:

- Commander and deputy portrait JPGs.
- `IJAMBO RYA MBERE INKOTANYI ZAKUBWIYE BY BONHOMME.mp3` for optional background audio.
- `rwanda-1994-administrative-divisions.svg` for the historical map overlay.
- `rwanda-relief-location-map.jpg`, currently available as a static reference asset.

## Generated And Local Directories

- `node_modules/` is local dependency installation output.
- `dist/` is generated by `npm run build`.
- `.vercel/` links the repo to the Vercel project.
- `.git/` tracks repository history.

Do not hand-edit `dist/` for source changes. Edit `src/`, `data/`, `index.html`, or `public/`, then rebuild.
